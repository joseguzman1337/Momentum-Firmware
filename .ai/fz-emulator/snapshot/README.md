# Sanitized Flipper hardware fixture

This directory is generated by `scripts/fz_emulator_snapshot.py` from the
connected Flipper Zero using only read-only CLI commands plus a temporary RPC
`ScreenStream` session. The stream is explicitly stopped. The capture performs
no persistent writes, reset, firmware update, GPIO operation, or application
launch.

The fixture contains hardware/firmware capability fields, storage metadata for
allow-listed paths, checksums of non-secret internal settings, USB descriptors,
local firmware package metadata, and one native 128x64 1bpp framebuffer.
Device UID, BLE MAC, serial number, hardware name, storage label, pairing data,
key material, and file contents are excluded or redacted.

Recreate it with the toolchain Python (which provides `pyserial`):

```sh
./toolchain/arm64-darwin/bin/python3 scripts/fz_emulator_snapshot.py \
  --port /dev/cu.usbmodemflip_REDACTED1 \
  --output .ai/fz-emulator/snapshot \
  --artifact path/to/firmware.dfu \
  --artifact path/to/update.fuf
```
