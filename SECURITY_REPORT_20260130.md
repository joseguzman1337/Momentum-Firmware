## Implemented Fixes

### 1. Power Service: Charge Suppression Counter Underflow
- **File:** `targets/f7/furi_hal/furi_hal_power.c`
- **Issue:** The `suppress_charge` counter (uint8_t) was decremented without checking if it was greater than 0. This could lead to a wrap-around to 255, permanently disabling charging until 255 more increments occurred.
- **Fix:** Added `furi_check(furi_hal_power.suppress_charge > 0)` to prevent underflow and assist in debugging mismatched caller logic.
- **Impact:** Improved reliability of the "Charge Cap" feature and general power management.

### 2. MJS Library: OOB Write and Use-After-Free in `mg_avprintf`
- **File:** `lib/mjs/common/str_util.c`
- **Issue:** (CodeQL Alert #4) If `vsnprintf` failed or memory allocation failed, the code attempted to write a null terminator at index -1 of a potentially freed buffer.
- **Fix:** Added a check `if (len >= 0)` before attempting to write the null terminator.
- **Impact:** Eliminated a potential crash and security vulnerability in the JavaScript runtime.
